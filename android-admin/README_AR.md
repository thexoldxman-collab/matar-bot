# تطبيق Matar Admin (Android)

تطبيق إدارة أصلي لأندرويد، مبني بـ Kotlin وJetpack Compose، باللغة العربية واتجاه من اليمين لليسار، مع وضع ليلي/نهاري/تلقائي.

## الدخول والأمان
- يرسل المالك أو المشرف المصرّح له الأمر `/adminapp` إلى بوت مطر، ثم يدخل رمز الربط الذي يرسله البوت. الرمز مؤقت ولمرة واحدة.
- الخادم هو المرجع الوحيد للدور والصلاحيات؛ التطبيق لا يقرر بنفسه من هو المالك أو المشرف.
- رمز الجلسة يُخزّن بتشفير Android Keystore/EncryptedSharedPreferences، ولا تُضمّن مفاتيح Telegram أو Neon في التطبيق.
- إجراءات الشحن والسحب وتعديل الأرصدة وصرف الإحالات تبقى مقفلة على الخادم افتراضياً، ولا يجب تفعيلها إلا بعد مراجعة واعتماد المالك.

## الأقسام الموصولة بالخادم
- لوحة مؤشرات الإدارة.
- غرفة العمليات واستلام الطلبات وتحرير الاستلام بمهلة عشر دقائق.
- البحث عن المستخدمين وعرض أرصدتهم، وتغيير حالة الحساب أو مراسلته.
- إدارة المشرفين وصلاحياتهم.
- إرسال الرسائل الجماعية مع نافذة تأكيد.
- تعديل أزرار البوت ونصوصه وإعداد الاشتراك الإجباري.
- عرض الإحالات وتعديل النسبة والدورة وموعد الدفعة.
- المساعد الذكي للاستفسار والتحليل؛ يقدم اقتراحات فقط ولا ينفّذ تغييرات تلقائياً.
- تفضيلات الإشعارات وسجل التدقيق.

## حدود نسخة الاختبار
- هذه نسخة Debug للاختبار وليست إصداراً نهائياً موقعاً للنشر.
- إشعارات الخلفية تستخدم فحصاً دورياً عبر Android WorkManager؛ ليست إشعارات فورية مضمونة، وقد يتأخر وصولها بحسب قيود أندرويد والاتصال.
- شاشة تعديل أرصدة المستخدمين وصرف أرباح الإحالات غير متاحة كإجراء مالي حقيقي في هذه النسخة.
- إعدادات مزودي الدفع والعجلة وبعض أدوات التشغيل المتقدمة لم تُدمج بعد في واجهة Android؛ لا تعتبر هذه النسخة مكافئة لكل وظائف إدارة تيليغرام.
- لم يُجرَ اختبار تثبيت وتشغيل على جهاز أندرويد فعلي؛ يلزم اختبارها بعد التثبيت قبل اعتمادها للإنتاج.

## البناء
افتح مجلد `android-admin` في Android Studio وابنِ مهمة `assembleDebug`. يحتاج المشروع إلى JDK 17 وAndroid SDK 35. يبني GitHub Actions ملف APK تجريبياً ويحفظه كـ Artifact.
