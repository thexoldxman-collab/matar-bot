# تطبيق Matar Admin (Android)

تطبيق Android أصلي باستخدام Kotlin وJetpack Compose، عربي من اليمين لليسار، مع وضع ليلي/نهاري/تلقائي.

## الحالة الحالية
هذه **نسخة تأسيسية للواجهة والمعاينة** وليست إصداراً إنتاجياً متصلاً. شاشة الربط لا تمنح الدخول؛ مصادقة تيليغرام والتحقق من الأدوار يحتاجان إلى خدمة خادم موثقة. المعاينة لا تنفذ معاملات أو ترسل رسائل حقيقية، وكل الأرقام والطلبات المعروضة تجريبية.

## أقسام الواجهة
- لوحة رئيسية ومؤشرات حالة
- غرفة عمليات: تنفيذ الطلب، إجراء، وتم التنفيذ (محاكاة محلية فقط)
- إدارة المشرفين (عرض توضيحي)
- الرسائل (واجهة فقط حتى ربط الخادم)
- إعدادات الإشعارات والمظهر وسجل التدقيق

## البناء
افتح المجلد `android-admin` في Android Studio ثم ابنِ مهمة `assembleDebug`. يحتاج Android SDK 35 وJDK 17.

يعمل سير GitHub Actions على بناء APK تجريبي وحفظه كملف Artifact عند دفع تغييرات هذا المجلد. قبل الاستخدام الحقيقي يجب إعداد رابط API HTTPS، مصادقة Telegram server-side، FCM، قواعد الصلاحيات، وسجل التدقيق، ثم اختبارات أمنية وتشغيلية.

## حدود الأمان
- لا تخزّن أسرار Telegram أو Neon داخل APK.
- لا تثق بدور يرسله العميل؛ الخادم هو المرجع الوحيد للصلاحيات.
- يجب قفل طلب الشحن/السحب ذرياً على الخادم مع مهلة انتهاء للمطالبة، ومنع التكرار، وتسجيل كل خطوة.
- التشغيل المالي الحقيقي يبقى معطلاً حتى اعتماد المالك صراحةً على الخادم.
